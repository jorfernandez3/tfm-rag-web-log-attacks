# Chapter review PDFs

This folder contains separate PDF files for reviewing the thesis chapters individually.

- [Chapter 1 - Introduction](chapter_01.pdf)
- [Chapter 2 - Background and Related Work](chapter_02.pdf)
- [Chapter 3 - Research Methodology](chapter_03.pdf)

The PDFs can be regenerated from the `thesis/` directory with:

```bash
bash build_review_chapters.sh
```

The complete thesis remains available as `main.pdf`. Chapters 4-8 are not included in this review package yet because they are still being written and reviewed.
